# Projeto: Testes de Test Doubles com Java e Maven

## Descrição

Este projeto tem como objetivo demonstrar a utilização de **Test Doubles** em testes automatizados com Java. São apresentados cinco tipos de objetos utilizados para substituir dependências reais durante a execução dos testes: **Dummy, Stub, Fake, Spy e Mock**.

O projeto utiliza **JUnit 5** para a criação e execução dos testes automatizados, **Mockito** para a criação de objetos simulados e **Maven** para o gerenciamento de dependências e organização da estrutura do projeto.

## Objetivos

- Compreender o conceito de Test Doubles.
- Identificar as diferenças entre Dummy, Stub, Fake, Spy e Mock.
- Praticar a criação de testes unitários.
- Isolar dependências para testar o comportamento de uma classe.
- Verificar resultados e interações entre objetos.

## Tecnologias utilizadas

- Java
- Maven
- JUnit 5
- Mockito
- IntelliJ IDEA

## Estrutura do projeto

- `src/main/java`: contém o código principal da aplicação.
- `src/test/java`: contém os testes automatizados.
- `pom.xml`: arquivo de configuração do Maven e das dependências.

## Resultado esperado

Ao executar os testes, é possível observar na prática como cada tipo de Test Double pode auxiliar na validação do comportamento do sistema, tornando os testes mais organizados, independentes e confiáveis.
